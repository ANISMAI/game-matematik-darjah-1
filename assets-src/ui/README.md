# Scroll material textures

Generated with the built-in image_gen tool, 19 October 2026. Source PNGs are preserved here; the app uses optimized WebP files under `public/ui/`.

- Paper source: `assets-src/ui/scroll-paper.png`; app asset: `public/ui/scroll-paper.webp`.
- Wood source: `assets-src/ui/scroll-wood.png`; app asset: `public/ui/scroll-wood.webp`.
- Rebuild optimized assets with `npm run images` (or `npm.cmd run images` in PowerShell).

## Paper prompt

Use case: photorealistic-natural. Asset type: seamless material texture for the background of a readable game UI parchment scroll. Primary request: a flat front-facing macro scan of real warm ivory handmade washi parchment paper, filling the entire square image edge to edge. Materials: visible fine organic paper fibres, delicate tiny flecks, very subtle cloudy cream variation, a few faint flattened creases. Low contrast and bright enough for dark text over it. Uniform diffuse lighting, no directional shadows or perspective. The tone is pale cream, not orange or brown. Constraints: only the material surface, tileable seamless edges, no sheet outline, no border, no rolled edges, no text, symbols, illustrations, objects, stains, holes or watermark. 1024 by 1024.

## Wood prompt

Use case: photorealistic-natural. Asset type: seamless horizontal wood grain material texture for the narrow cylindrical wooden rods of a children's ninja game parchment scroll. Primary request: a flat orthographic macro material scan of warm honey-brown aged hardwood, with fine horizontal wood grain running left to right, filling image edge to edge. Subtle tactile pores, elegant long flowing grain lines, small natural variations, softly worn smooth finish. Real material with a gentle painterly game-art polish, rich amber chestnut brown, moderately low contrast. Uniform neutral lighting, no shadows baked in. Constraints: only the continuous material surface, seamless tileable edges, no plank boundaries, no perspective, no object outline, no text, nails, screws, logos, cracks or watermark. 1024 by 1024.
